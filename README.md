# دعوة فرح — أحمد & عبير

دعوة سينمائية ثلاثية الأبعاد: عالم واحد في ستة فصول — الباب، الأسماء بالألعاب النارية، العدّ التنازلي عند الهلال،
العروسان تحت الشجرة، تأكيد الحضور عند القوس، والختام في السماء. Next.js + three.js.

```bash
npm install
npm run dev                  # تطوير على http://localhost:3000
npm run build && npm start   # النسخة النهائية
```

## التنقّل
السحب من اليسار لليمين = الفصل التالي، الأسهم، النقاط، الكيبورد، عجلة الماوس، أو لمس القمر/الشجرة/القوس/البحيرة/السماء.
لكل فصل رابط: `#door` `#names` `#countdown` `#couple` `#rsvp` `#sky`.

## الأسماء
تبدأ الألعاب النارية بكتابة «أحمد ♥ عبير» لحظة انفتاح الباب (بعد ١٫٦ ثانية من بدء الحركة): الصاروخ الأول يصعد من خلال فتحة الباب،
والأسماء تتشكّل والضيف يمشي في الممر. لو دخل الضيف برابط مباشر `#names` تبدأ عند الوصول كما كانت.

## الألعاب والمفاجآت — معاينة فقط
**لا تظهر في الدعوة العادية.** افتحها بإضافة `?games=1`: مثلًا `http://localhost:3000/?games=1#couple`.
- **القلوب الخمسة** («اكتشف أسرار الحديقة») داخل الفصول نفسها، كل واحد يظهر في لقطة فصله على شاشة موبايل عمودية بعيدًا عن الكلام والأزرار:
  الباب (تاج العمود الأيسر) · الأسماء (كتف القوس الأيسر) · العروسان (معلّق في الشجرة فوق العريس، وعائم مع الشموع على البحيرة) · تأكيد الحضور (بين البتلات على الممر).
  الخمسة ياقوتات حمراء متطابقة: لامعة، بهالة حمراء خفيفة (أخفت قليلًا في الحديقة منها على الباب المضاء)، ولمعات تومض وتمرّ على سطحها.
  التقدّم محفوظ على جهاز الضيف فقط (`localStorage`). عند الخامس: رجوع لسماء الأسماء، ألعاب نارية ذهبية، والأسماء مرة أخرى.
- **مداخل الألعاب في الحديقة**: لافتة «تحدي العروسين» عند جذع شجرة الثريا (تظهر في فصل العروسين)،
  ركن الكرة «تحدي العروسة» على العشب الأيمن عند الشاطئ، وكتاب «اكتب أمنيتك» على الشاطئ الأيسر بين الشموع (الاثنان بـ«استكشف» من فصل الحضور: ٣٥° يمينًا، ٣٠° يسارًا).
- **«استكشف»**: الكاميرا تطير إلى نقطة نظر عند الباب، فوق أول الممر `(−1.2, 3.8, −7.5)`، وترجع لنفس الفصل بـ«العودة للفصل».
  هناك: السحب يلفّ النظر (دورة كاملة، وفوق حتى القمر وتحت حتى العشب)، والتقريب بإصبعين أو بزرّي + و− أو بعجلة الماوس حتى ×٤ — الرأس يلفّ والعدسة تضيق فقط، فلا شيء يُخترق.
  في الاستكشاف فقط: الآية فوق القمر والعدّ التنازلي تحته في السماء البعيدة، يكبران بالتقريب، ويختفيان عند الخروج. فصل العدّ التنازلي وآية الختام كما هما.
  اختيرت النقطة بالقياس من ١٥٠ نقطة عند الباب: لا شيء صلب بين العين وأي قلب أو مدخل لعبة أو القمر أو الآية أو العدّ.
  أثناء الاستكشاف كل قلب لم يُكتشف له وهج ثابت الحجم على الشاشة.
  مع التقريب (من ×١٫١٥ إلى ×١٫٩) والآية أو العدّ في الصورة، تصير أوراق الشجر شفافة تدريجيًا (حتى ٢٠٪) فيظهر ما خلفها؛ تعود كما هي بالابتعاد أو بالالتفات عنهما.
- **رسالة الباب** («هل أنت مستعد للمغامرة؟»): ورقة على الباب، مفتوحة عند تحميل الصفحة. × يلفّها إلى لفافة مختومة — بلا حد، ولا يفتح الباب.
  وهي ملفوفة تتدلّى تحتها لافتة خشب جوز ثلاثية الأبعاد «افتح الرسالة» (حروف محفورة مذهّبة) على حبلين من خطّافين نحاسيين في القائم الخشبي عند منتصف الباب
  (خطّاف على كل ضلفة، فيفتحان معه)؛ تنزل بتأرجح خفيف وتهتزّ مع النسيم، ولمسها يفتح الرسالة. بعيدة عن قلب الباب والمقابض.
  «ابدأ المغامرة» قصاصة رقّ ممزّقة ثلاثية الأبعاد على الرسالة (سُمك، أطراف ملتفّة ومطويّة، ظل على الورقة، تذهيب خفيف)؛ الكلمات نص الصفحة مطبوع عليها.
  عند اللمس: تنضغط القصاصة وترتفع أطرافها، شرارات ذهبية، تخفت الكلمات، ثم تُلفّ الرسالة وتُرفع ويبدأ تسلسل الباب كما هو (≈ ٠٫١٦ ث زيادة قبله، توقيت الأسماء من الباب لم يتغيّر).
  النص في `lib/games/poster.js`، والرسالة واللافتة والقصاصة في `createLetter` بـ`lib/cinematic/garden.js`.
- **«الألعاب»**: خريطة الحديقة بالميداليات الأربع. اسم الضيف اختياري (يُسأل مرة، ويمكن تخطّيه)، لا يُرسل لأي مكان ولا علاقة له بتأكيد الحضور.
- أي لعبة تفتح فوق الدعوة: العالم يتوقف عن الرسم، و«رجوع» يعيد الضيف لنفس الفصل ونفس المكان بدون إعادة الباب.

### ⚠ قبل الاعتماد
- **أسئلة «تحدي العروسين» وإجاباتها غير معتمدة.** الأسئلة الخمسة في `lib/games/quiz.js` هي أمثلة، والإجابات `null` عمدًا.
  ضع لكل سؤال `answer: 'ahmed'` أو `'abeer'` ثم `approved: true`. حتى ذلك الحين لا تظهر نتيجة، ويُقال للضيف إن العروسين سيكشفان الإجابات.
- **قراءة الأمنيات**: اضبط مفتاحًا سرّيًا (١٦ حرفًا على الأقل) في متغيّر البيئة `WISHES_KEY` على السيرفر، ثم افتح `/wishes` واكتبه.
  بدون مفتاح مضبوط القراءة مغلقة على الجميع. لا تكتب المفتاح في الكود. للاختبار: `WISHES_FILE=/tmp/w.json`.
  `wishes.json` مثل `rsvp.json`: يحتاج سيرفر Node دائم.

## الأداء
- العالم ثلاثي الأبعاد يُحمَّل بعد أول ظهور؛ قبله تظهر صورة الفصل الثابتة.
- ثلاث درجات جودة (desktop / mobile / low) حسب الجهاز — دقة الرسم ١٫٥ / ١٫٢٥ / ١ — وتنخفض تلقائيًا لو الجهاز بطيء (يُقاس كل ٦٠ إطارًا).
- كل الـshaders تُجهَّز قبل أول إطار (حتى الحديقة خلف الباب والألعاب النارية)، فلا شيء يُترجم أثناء فتح الباب.
- 30 إطارًا في الثانية على الموبايل حين لا شيء يتحرك، والجزيئات لا تُرسم حين لا شيء في السماء.
- الرسم يتوقف حين تكون الصفحة مخفية، ودعم `prefers-reduced-motion`.

## أدوات
`?slowmo=10` يبطّئ الحركة · `?still=1` وضع التصوير · `?debug=1` أرقام الرسم في `window.__cine` (ومعه `?games=1`: `__cine.garden()` أماكن القلوب والمداخل على الشاشة) · `?games=1` معاينة الألعاب.
**بعد أي تعديل في المشهد** أعد توليد الصور الثابتة (لكل فصل بوضع `?still=1`: عمودي 390×844@2x وأفقي 1280×720، WebP)
ثم `npm run build` — Next.js لا يقدّم إلا ملفات `public/` الموجودة وقت البناء.
للاختبار دون لمس قائمة الضيوف: `RSVP_FILE=/tmp/test.json npm start`.

## GitHub Pages deployment

The current version is a static site without a backend. Online RSVP, wish
submission, and the private wishes reader are disabled; no guest information
is sent or stored. The original API source is preserved in `backend-disabled/`
outside the Next.js route tree. Existing JSON data is not exported.

In repository Settings ? Pages, select GitHub Actions. The workflow builds
with `output: 'export'` and publishes `out/`. It sets the repository base path
for project sites, including public image and texture URLs. For a custom domain,
the base path is empty. Locally run `npm run build` and serve `out/` using a
static server; `next start` is not used for this version.
