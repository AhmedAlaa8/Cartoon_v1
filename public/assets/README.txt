=====================================================
 صور العروسين (اختياري)
=====================================================
ضع هنا (في نفس المجلد public/assets):
  groom.jpg  /  bride.jpg      (أو ‎.png / .webp)
ثم أعد البناء:  npm run build
الصورة تظهر تلقائيًا داخل الميداليات المعلّقة في فصل «العروسان» مكان
الرسم الكرتوني (تُقصّ مربّعًا من المنتصف) — لا حاجة لتعديل أي كود.
يُفضّل صورة مربّعة تقريبًا ≈ 800×800 بحجم صغير (WebP/JPG).


=====================================================
 تأكيد الحضور (RSVP)
=====================================================
في فصل «تأكيد الحضور» عند القوس يكتب الضيف اسمه وعدد الأفراد،
وأي تأكيد يُكتب فورًا في الملف:  rsvp.json  (في جذر المشروع)

التشغيل:
  1) npm install          (مرة واحدة)
  2) npm run build
  3) npm start            ثم افتح  http://localhost:3000
  4) كل تأكيد حضور يظهر كعنصر جديد داخل rsvp.json
     مثال:
       [
         { "name": "محمد", "count": 2, "date": "..." }
       ]

ملاحظة: الكتابة في الملف تحتاج سيرفر Node حقيقي (npm start أو VPS).
على استضافة serverless مثل Vercel لن يُحفظ الملف — هناك تحتاج قاعدة
بيانات أو Google Sheet بدلًا منه.
